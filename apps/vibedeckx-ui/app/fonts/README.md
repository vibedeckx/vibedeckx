# Bundled fonts

Latin-subset variable/static WOFF2 files copied from Fontsource 5.3.0
(`@fontsource-variable/geist`, `@fontsource-variable/geist-mono`,
`@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`,
`@fontsource/instrument-serif`). All are licensed under the SIL Open Font
License 1.1.

They are loaded with `next/font/local` in `app/layout.tsx` so the build never
fetches from Google Fonts.
